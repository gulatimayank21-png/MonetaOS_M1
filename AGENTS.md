# Project Instructions & Permanent Guidelines

- **Mandatory System Spec Sync**: With every change made to the codebase (quantitative rules, calculations, UI components, data structures, or synchronization logic), **always update `main/docs/SYSTEM_SPEC.md` (and `docs/SYSTEM_SPEC.md`)** so that the system documentation is comprehensive, accurate, and reflects the current state of the application.
